# Hi, I'm Abhilasha Das 👋

### M.Sc. Data Science Student | Quantitative Analytics & Interpretable Machine Learning

Postgraduate student in Data Science at St. Xavier’s College (Autonomous), Kolkata, with an academic background in Economics from the University of Calcutta.

My work primarily revolves around machine learning, quantitative analysis, spatial data systems, and scientific computing workflows. I am interested in building analytical pipelines that are interpretable, computationally efficient, and grounded in careful statistical reasoning rather than relying only on predictive performance.

Recent work has included anomaly detection and machine learning on archaeological datasets from the Cuneiform Digital Library Initiative (CDLI), Earth observation workflows using satellite-derived indicators, and statistical modeling projects focused on structural pattern analysis across real-world datasets.

I am particularly interested in problems where mathematics, domain understanding, and computational methods intersect in a practical and research-oriented way.
